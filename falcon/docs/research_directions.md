# 新規探索の方向（2026-08-22 開始）

査読でトップ会議と戦うには「新しい結果」が要る。2024/1709 が同じ土俵を
先取りしているので、その主張を**拡張・反証・定量化**する角度を狙う。

各方向は「仮説 / 最初の実験 / 判定基準 / 状態」で管理する。否定的結果も

## 1. 差分テスト器の自動化（方法論の主柱）
- **仮説**: FALCON の FP 演算のうち署名に届くのは少数の特定箇所であり、
  それを網羅列挙できる。
- **実験**: 各 FP 原始関数（`div_fft`, `mul_fft`, `add_fft`, `sub_fft`,
  `split_fft`, `merge_fft`, ...）の出力を1 ulp（`nextafter`）だけ摂動する
  フックを入れ、署名の発散率を測る。呼び出し位置ごとに集計。
- **判定**: 「届く箇所の地図」ができれば方法論として成立。
- **状態**: 未着手。

## 2. 第5の敏感位置（chosen-message）★最有望
- **仮説**: 2024/1709 は敏感位置を 4 つに限定するが、それは**乱数メッセージ
  に対する確率的**な主張。g_k が FP 精度内なのは最初/最後の**6回**まで
  （論文 p.16 自身が認める）。メッセージを選べる攻撃者は c2/c3 等の
  中間位置も整数中心に追い込め、攻撃面が広がる。
- **実験**: 1鍵固定、メッセージを振って各位置の中心 |mu−round(mu)| を記録。
  位置 2,3,4,5 と 2n−3..2n−6 が整数近傍になる頻度を測る。近傍を引いたら
  2 綴りで発散するか確認。
- **判定**: 位置 0,1,2n−2,2n−1 以外で発散を1件でも示せれば拡張成立。
- **状態**: 内部（乱数メッセージ）は ✗ 負（~10⁷ ドローで整数中心なし、#058）。
  chosen-message での探索は未着手（最初/最後の6回まで FP 精度内）。

## 3. 弱鍵クラス（FP-決定性に対する）★安い
- **仮説**: 最後の2回の発散率 = 1/‖(g,−f)‖²。‖(g,−f)‖² の分布には裾があり、
  小さい鍵は構造的に漏れやすい「弱鍵」。
- **実験**: N 鍵で ‖(g,−f)‖² の分布（min/max/裾）を測る。最小の鍵で
  発散率が実際に上がるか確認。他の不変量（m_2, m_3）とも相関。
- **判定**: 明確な裾＋率の鍵依存を定量化できれば結果になる。
- **状態**: ✗ 負の結果。3000鍵で ‖(g,−f)‖² は 15078〜16822 に密集（1.09×）、
  keygen が 1.17²q で棄却するため裾なし。率はほぼ鍵非依存（#058）。

## 4. §6.1 の非対称性を解く
- **仮説**: 「整数中心を条件づけると最後の2回が最初の2回より発散しやすく、
  dyn/tree 特有」を説明できる。
- **実験**: 整数中心イベントを両端で集め、条件付き発散確率を分解。
  dyn/tree の演算順序差が中心の摂動幅にどう効くかを追う。
- **状態**: ✓ 解決（#058）。摂動 |dmu| は木の降下で累積し、位置512（z1/z0境界）で
  ~7倍の段。最後の2回は z0 最深部で最初の2回（z1）の 32倍。A2 は先頭を厳密に
  0 摂動。paper §6.3。

## 5. 塩非依存の中心 → 通常 Falcon への含意
- **仮説**: 呼び出し1,2の中心は塩・乱数に依存しない（実測済み #057）。
  salted な通常 Falcon でも同一メッセージなら中心が固定 → 複数実装/複数署名
  にまたがる相関漏洩がありうる。
- **実験**: 同一メッセージ・異なる塩で calls 1,2 の中心が一定かを確認済み。
  それが plain Falcon で何を許すかを詰める。
- **状態**: 部分観測済み、含意は未詰め。

## 6. 精度 vs 漏洩率

- **状態**: 未着手。
